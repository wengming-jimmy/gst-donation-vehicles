# GST 八大志業捐車紀錄

國際獅子會 300A-2 區 GST 八大志業社服活動看板用：彙整各分會歷年捐贈車輛的服務成果。

## 連結

- 前台：https://wengming-jimmy.github.io/gst-donation-vehicles/
- 後台：同網址加 admin.html（**勿公開**，首次自設密碼）
- 試算表：「GST捐車紀錄」
- 照片：Drive 資料夾「GST捐車紀錄照片」

## 欄位（試算表 7 欄）

填寫時間、捐贈分會、捐贈年度（民國年）、捐贈車輛、受贈單位、捐贈照片（Drive 連結）、備註。

## 規則

- 每筆捐車紀錄分開填寫，每筆各附一張交車照片（建議看見車輛及受贈單位）。
- 照片前台會先縮到最長邊 1600px 再上傳，存進 Drive 資料夾，檔名含年度、分會、車輛與時間。
- 後台可重新載入、刪除、匯出 CSV；刪除只刪試算表該列，Drive 照片檔需另外到資料夾刪除。
- Code.gs 只放 Apps Script、不要推上公開庫；config.js 的 API_URL 填正式 /exec 網址。
